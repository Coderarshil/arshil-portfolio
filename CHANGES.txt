Resume viewer update — 2026-09-27

- Replaced the two-card resume chooser with a single centered resume viewer.
- Resume pages are shown as high-resolution WebP renders derived from the existing resume PDF.
- Added previous/next page arrows.
- Added zoom controls (desktop toolbar + compact mobile controls).
- Added one download icon that downloads the original /resume.pdf.
- Added an X close button.
- Added a single “Wanna fly” action below the resume.
- “Wanna fly” hides the PDF controls, switches to the galaxy scene, and starts the folding paper-plane animation.
- At the end of the animation, the action becomes “Landing”; clicking it returns to the PDF viewer.
- Removed the old Fold Resume / Reset controls from the 3D page.
- Disabled 3D zoom; the 3D scene is controlled by the parent viewer during the flight sequence.
