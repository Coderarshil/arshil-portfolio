Portfolio setup

1. Install dependencies:
   npm install

2. Start development:
   npm run dev

3. Production build:
   npm run build

PDF.js is included as a build-time dependency and is copied into public/pdfjs automatically by the prepare:pdfjs script. The resume viewer and the 3D folding resume both use the single public/resume.pdf file.

The public/resume.pdf file is the optimized A4 resume and is also the file downloaded by the Resume viewer.
